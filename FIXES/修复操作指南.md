## ⚠️ 重要注意事项

### 类型变更影响

以下字段类型已修改，可能影响现有代码:

1. **SysUser.gender**: `String` → `Integer`
   - 旧值: "M", "F"
   - 新值: 0 (未知), 1 (男), 2 (女)

2. **SportItem.genderLimit**: `String` → `Integer`
   - 旧值: "M", "F", "ALL"
   - 新值: 0 (不限), 1 (仅男), 2 (仅女)

3. **Registration.status**: `String` → `Integer`
   - 旧值: "PENDING", "APPROVED", "REJECTED", "CANCELLED"
   - 新值: 1, 2, 3, 4

4. **Schedule.status**: `String` → `Integer`
   - 旧值: "PENDING", "ONGOING", "FINISHED", "CANCELLED"
   - 新值: 1, 2, 3, 4

5. **News.isTop**: `Boolean` → `Integer`
   - 旧值: true, false
   - 新值: 0, 1

6. **News.status**: `String` → `Integer`
   - 旧值: "DRAFT", "PUBLISHED"
   - 新值: 0, 1

## 🐛 常见问题

### Q1: 编译时提示找不到 @TableField
**A**: 确保导入了正确的包:
```java

```

### Q2: 启动时仍然报 Unknown column 错误
**A**:
1. 确认数据库脚本已执行
2. 检查实体类文件是否保存
3. 执行 `mvn clean compile` 清理旧编译文件
4. 重启应用

### Q3: gender/status 等字段值显示不正确
**A**: 类型已从 String 改为 Integer，需要更新:
- 数据库现有数据（如需要）
- 前端枚举映射
