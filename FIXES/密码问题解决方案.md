## ⚠️ 问题原因分析

### 可能原因 1: 密码哈希不匹配
**现象：** 数据库中的密码哈希不是用你尝试的密码生成的。

**解决：** 使用上述方法 1 或 2 重置密码。

---

### 可能原因 2: 数据库未更新
**现象：** 执行了更新脚本但密码仍然错误。

**检查步骤：**
1. 确认 SQL 脚本执行成功（无错误提示）
2. 查询数据库确认密码已更新：
   ```sql
   SELECT username, LEFT(password, 30), update_time
   FROM sys_user
   WHERE username = 'admin';
   ```
3. 检查 `update_time` 字段是否是最新时间

---

### 可能原因 3: 应用未重启
**现象：** 数据库已更新但登录仍然失败。

**解决：**
1. 停止 Spring Boot 应用（Ctrl+C）
2. 重新启动：`mvn spring-boot:run`
3. 清理浏览器缓存
4. 重新尝试登录

---

### 可能原因 4: BCrypt 配置问题
**现象：** PasswordEncoder 配置不正确。

**检查配置类：**
```java
// 查找 SecurityConfig 或类似配置文件
@Bean
public PasswordEncoder passwordEncoder() {
    return new BCryptPasswordEncoder();
}
```

**验证：** 运行 `PasswordTester.java` 查看是否能正确验证密码。
