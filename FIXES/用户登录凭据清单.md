```sql
SELECT
    id,
    username,
    real_name,
    role,
    status,
    LEFT(password, 30) as password_preview,
    update_time
FROM sys_user
WHERE is_deleted = 0
ORDER BY
    CASE role
        WHEN 'ADMIN' THEN 1
```

## 🚨 常见问题

### Q1: 某个用户无法登录
**检查步骤：**
1. 确认用户状态是否为启用（status = 1）
2. 确认密码哈希是否正确
3. 确认 is_deleted = 0
4. 重启应用

**SQL 检查：**
```sql
SELECT username, status, is_deleted, LEFT(password, 30)
FROM sys_user
WHERE username = '用户名';
```

---

### Q2: 所有用户都无法登录
**可能原因：**
1. 密码哈希未正确更新
2. PasswordEncoder 配置错误
3. 应用未重启

**解决方案：**
1. 重新执行密码重置脚本
2. 运行 `PasswordTester.java` 验证
3. 重启应用

---

### Q3: 需要为特定用户设置不同密码
**执行 SQL：**
```sql
-- 为 admin 单独设置密码为 admin123
UPDATE sys_user
SET password = '$2a$10$2K7LqOXqAGD0VrXz8b.FweZQKvKvqGV7xqPFqR3qPLqnQx5VQ5GKm'
WHERE username = 'admin';
```

或使用 `PasswordGenerator.java` 生成新密码哈希。
