## 6. MVP 演示脚本

### 6.1 演示场景1：管理员创建赛事

```
1. 管理员登录 (admin/admin123)
2. 进入赛事管理页面
3. 点击"新增"按钮
4. 填写赛事信息：
   - 赛事名称：2024年春季运动会
   - 赛事类型：田径运动会
   - 开始日期：2024-04-15
   - 结束日期：2024-04-17
   - 报名截止：2024-04-10
5. 保存赛事
6. 添加比赛项目：男子100米、女子100米、男子跳远
7. 编排赛程：设置比赛时间和场地
8. 发布公告：报名通知
9. 变更赛事状态为"报名中"
```

### 6.2 演示场景2：学生报名参赛

```
1. 学生登录 (student01/admin123)
2. 进入赛事大厅
3. 查看赛事列表
4. 点击"2024年春季运动会"
5. 查看赛事详情和项目列表
6. 选择"男子100米"项目
7. 点击"报名"按钮
8. 确认报名
9. 查看"我的报名"，状态为"待审核"
```

### 6.3 演示场景3：教师录入成绩

```
1. 教师登录 (teacher01/admin123)
2. 进入报名管理
3. 审核学生报名（通过）
4. 进入成绩管理
5. 选择赛事和项目
6. 方式一：逐个录入成绩
7. 方式二：下载Excel模板，填写后导入
8. 查看成绩排名
9. 导出成绩Excel
```

### 6.4 演示场景4：数据统计展示

```
1. 管理员登录
2. 进入首页Dashboard
3. 查看统计概览：
   - 赛事总数
   - 报名总数
   - 成绩录入数
4. 查看报名统计图表（柱状图）
5. 查看成绩分布图表（饼图）
```
