# 学生检录信息与导航调整

## 学生个人赛程接口

- `GET /api/checkins/my`
- 权限：`STUDENT`
- 返回本人已审核通过且已进入赛程编排的个人项目和接力项目。
- 返回字段包括赛事、项目、场次、比赛时间、地点、组别、道次/出场顺序、检录状态、检录备注，以及已正式发布的成绩信息。

## 检录编号

检录编号由参赛编排记录的数据库主键确定，格式为 `CK` 加八位数字，例如 `CK00001234`。该编号稳定且唯一，不需要新增数据库列；秩序册 CSV、赛事工作人员的竞赛执行页面和学生个人赛程页面使用同一编号。

## 导航分组

侧边栏按业务流程分组：

- 工作台
- 赛前准备：赛事管理、运动项目、报名管理、接力组队
- 我的参赛：我的报名、我的赛程与检录号、我的成绩
- 赛程与检录：赛程安排、竞赛执行与现场检录
- 成绩管理：成绩录入与审核发布
- 赛事信息：新闻公告
- 统计报表：统计分析、学院积分与奖牌榜
- 系统管理：用户管理

## 权限约束

- 学生可以查看赛程和个人检录编号，不显示赛程新增、编辑、开始、结束和删除等管理操作。
- 教师和管理员可以进入竞赛执行页面；赛程的创建、编辑和删除操作仅向管理员展示。
- 学生个人检录接口以当前登录用户 ID 查询数据，不接受客户端传入用户 ID，避免通过修改参数查看其他学生信息。

## 验收建议

1. 使用学生账号登录，确认只能查看本人的个人项目及所在接力队伍的检录编号。
2. 使用教师账号登录，确认可进入竞赛执行与现场检录页面，但不能创建或删除赛程。
3. 使用管理员账号登录，确认赛程管理按钮正常显示。
4. 导出秩序册 CSV，确认检录编号列与页面显示编号一致。
5. 对未编排、未审核通过或未发布的记录，确认页面分别显示空列表或“尚未发布”，不虚构成绩。
