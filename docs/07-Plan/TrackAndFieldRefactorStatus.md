# 高校田径运动会改造记录

开发分支：`codex/campus-track-meet-foundation`

## 本次已提交的基线修复

- 将数据库 URL、用户名、密码与 JWT 签名密钥改为环境变量配置；将常规应用与 Spring Security 日志默认级别调整为 INFO。
- 报名审核状态统一映射为前端兼容的 `PENDING / APPROVED / REJECTED / CANCELLED`，后端查询时映射到数据库整数状态 1–4。
- 修正“我的报名”接口，使其支持分页与状态筛选；对齐前端审核时间、审核意见字段名。
- 报名审核拒绝接口改为接收 JSON `reason`，与前端请求结构一致。
- 报名校验增加学生用户存在性、人数上限为 0 表示不限、可空报名日期处理；拒绝无效审核状态。
- 将成绩实体与现有 `result` 表字段对齐：加入 `registration_id`、`score_text`、`record_by`、`record_time` 映射，移除数据库不存在的 `is_record` 映射。
- 成绩录入要求关联已审核通过且赛事、项目匹配的报名记录；排名按成绩类型和当前场次计算，同成绩采用并列名次规则。
- 新增不删除旧表的增量迁移脚本，建立接力队伍/队员、场次参赛条目、检录、田赛试跳试投、积分规则及成绩审计日志的基础表。
- README 增加环境变量设置与安全迁移提示。

## 数据库迁移

文件：`backend/src/main/resources/db/migration/V1__campus_track_meet_additive.sql`

该脚本使用 `CREATE TABLE IF NOT EXISTS` 增量建表，不会删除或清空既有表。执行前仍须备份数据库并核验现有表结构、外键和数据库权限。不要在现有业务库中重新执行包含 `DROP TABLE` 的 `docs/04-DB/schema.sql`。
