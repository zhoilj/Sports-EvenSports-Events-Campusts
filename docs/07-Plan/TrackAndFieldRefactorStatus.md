# 高校田径运动会管理系统改造记录

开发分支：`codex/campus-track-meet-foundation`

## 基线与自动化验证

- 后端：Java 17、Maven `clean verify`。
- 前端：Node.js 20、`npm ci`、`npm run build:check`，执行 Vue/TypeScript 检查和 Vite 生产构建。
- 数据库：GitHub Actions 在隔离 MySQL 8.0 实例中执行基础 schema 与 V1、V2、V3 增量迁移，并检查关键表和字段。
- 自动化记录：[GitHub Actions](https://github.com/zhoilj/Sports-EvenSports-Events-Campusts/actions/workflows/build.yml)。

## 第一阶段报名模块

- 个人报名接口限制学生角色，并核验账号状态、赛事报名状态、报名日期、项目状态、项目归属和性别限制。
- 赛事增加每人限报项目数；0 表示不限。项目容量按有效报名记录计算，使用事务锁降低并发超限风险。
- 取消/拒绝后可复用报名记录，当前报名数按有效状态重新计算。
- 报名管理增加学院、班级筛选和审核信息展示。
- 接力队伍支持创建、队员维护、资格核验、审核与取消；队员必须为状态正常且属于同一学院的学生，同一项目下不能重复加入多支待审/已通过队伍。
- 赛事详情提供接力组队入口。

## 第二阶段竞赛编排与现场执行

### 赛程管理

- 增加 `round_type`：预赛、半决赛、决赛和田赛决赛。
- 创建/修改赛程时检查日期范围、项目归属、开始/结束时间和同场地时间重叠。
- 生成参赛名单时，从已通过个人报名或接力队伍中创建场次参赛记录。
- 径赛按组别和道次分配；田赛按顺序号安排参赛顺序。
- 对同一参赛者在同日相近时段的其他赛程进行冲突检查；生成名单或开始赛程前发现冲突时阻止继续操作。
- 已生成名单的赛程不能随意更换项目、轮次或直接删除。

### 预赛与决赛晋级

- 只有已结束赛程中复核通过的有效成绩可以晋级。
- 支持按组直接晋级人数与总晋级人数组合生成下一轮名单。
- 晋级名单按成绩排序；对晋级边界的并列成绩进行保留，避免单纯按数据库顺序淘汰同成绩选手。
- 决赛晋级人数不能超过目标每组容量。

### 现场检录

- 参赛名单自动创建待检录记录。
- 支持已检录、缺席（DNS）、弃权（WD）和取消资格（DQ）。
- 终止状态同步生成相应成绩状态；已检录人员不能再被标记为缺席，终止状态不能直接恢复为普通状态。

### 田赛试跳与试投

- 每名参赛者可登记1—6次试跳/试投。
- 犯规成绩不计入最佳有效成绩；系统根据项目排序规则汇总最佳成绩，生成待复核成绩。
- 只有已检录参赛者可录入试跳/试投；赛程结束后才能汇总最终成绩。

## 第二阶段成绩复核与正式发布

- 成绩可以关联个人报名记录或接力队伍，且必须匹配同一赛事、项目和场次。
- 同一名运动员可在不同轮次分别保留成绩；唯一约束按场次区分。
- 有效成绩按项目规则排序，计时项目默认低值优先，距离/计分项目默认高值优先；相同成绩共享名次。
- 成绩支持待复核、复核通过、退回修改和正式发布。
- 只有赛程结束、所有参赛名额均有成绩记录且全部复核通过后，才能正式发布。
- 正式发布后禁止直接修改或删除；每次录入、修改、复核、退回、发布和删除均写入成绩审计记录。
- 预赛/半决赛不计团体积分；决赛/田赛决赛发布时按赛事配置的积分规则计算积分。决赛发布前必须先配置积分规则。

## 团体积分、奖牌榜与导出

- 新增学院积分与奖牌榜，统计正式发布的决赛成绩。
- 积分规则可按赛事配置名次和积分，支持同名次对应相同积分。
- 新增秩序册 CSV、正式成绩 CSV 和学院积分/奖牌榜 CSV 导出，文件采用 UTF-8 BOM 以兼容常见表格软件。
- 学生“我的成绩”可查看已正式发布的个人成绩和本人所属接力队伍成绩。

## 数据库迁移

依次执行：

1. `backend/src/main/resources/db/migration/V1__campus_track_meet_additive.sql`
2. `backend/src/main/resources/db/migration/V2__registration_compatibility_and_relay_config.sql`
3. `backend/src/main/resources/db/migration/V3__competition_operations.sql`

执行前必须备份目标数据库。V3 会将既有历史成绩标记为已复核/已发布（仅首次添加发布字段时执行），并支持接力队伍成绩。禁止在已有业务数据库上直接重跑包含 `DROP TABLE` 的 `docs/04-DB/schema.sql`。
